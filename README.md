## Publish with GitHub Pages
1. Sign in at https://github.com/new and create a public repository named `crispycloud-website`.
2. Extract this ZIP, then upload `index.html`, `style.css`, and the `assets` folder to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then Save.
5. Wait for the Pages deployment and open the website URL shown on the Pages screen.

Note: This package is ready for GitHub Pages, but it has not been uploaded to your GitHub account and no live repository URL exists yet. The cart is a front-end demo; customers are directed to Facebook to confirm orders. It does not collect online payments or save orders to a backend.
